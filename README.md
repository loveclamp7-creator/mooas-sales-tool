# 무아스 공동구매 매출 자동 정리 v5.0

왼쪽에 매출 원본 2개와 당월 캘린더 최신본을, 오른쪽에 누적 공동구매 리스트를 올리면 주문번호 기준 매출과 누락 일정을 함께 정리하는 Streamlit 앱입니다.

## 업로드 파일

왼쪽 `매출 원본 파일들`에는 다음 파일을 함께 올립니다.

1. `(주)스룩_오클릭.xls` 형식의 주문내역
   - `★판매처주문번호(수정가능)`
   - `품명`
   - `★결제액(수정가능)`
2. `차액_YYMM.xlsx` 형식의 파일
   - `상세내역_통합` 탭만 사용
   - `주문번호`
   - `상품명` (`셀러명 × 무아스 상품명`)
3. 당월 캘린더 최신본
   - `시작일 / 종료일 / 진행일 / 밴더사 / 셀러 / 셀러 링크 / 팔로워 / 품번 / 품목 / 공구명`

오른쪽 `결과 양식 파일`에는 `무아스 공동구매 리스트(26년도).xlsx` 형식의 누적 파일을 올립니다.

## 처리 규칙

- `상세내역_통합`의 주문번호로 셀러와 공구명을 확인합니다.
- 같은 주문번호의 실제 판매금액은 스룩 주문내역의 `★결제액(수정가능)`을 합산합니다.
- 한 주문에 여러 상품이 있으면 스룩 품명과 공구명을 비교해 각각 배분합니다.
- 캘린더 최신본에만 있는 일정은 진행일·밴더사·셀러·링크·팔로워·품번·품목·공구명을 새 행으로 추가합니다.
- 한 캘린더 일정에서 함께 판매한 추가 상품은 같은 셀러의 일정 매출에 합산합니다.
- 결과 양식의 기존 시트·서식·다른 월 데이터는 유지합니다.
- 선택한 최신 연도의 해당 월만 처리하며 기존 판매금액은 덮어쓰지 않습니다.
- 비즈브릭스, 레몬트리, 지엠홀딩스의 판매금액은 공란으로 유지합니다.
- 결과 파일에는 검수용 `매칭결과`, `주문번호매칭`, `캘린더에없는매출` 시트가 추가됩니다.
