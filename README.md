# 인플루언서 공동구매 매출 정리 프로그램

첨부한 `다운로드파일.xlsx` 같은 상품별 매출 파일을 업로드하면 아래 열만 정리합니다.

| 년 | 월 | 진행일 | 밴더사 | 셀러 | 품목 | 판매금액 |
|---|---|---|---|---|---|---:|

- `셀러`, `품목`: 상품명에서 자동 분리
- `판매금액`: 원본의 `정상금액` 사용
- `밴더사`: 등록된 셀러는 자동 입력, 없는 셀러는 빈칸
- `년`, `월`, `진행일`: 표에서 직접 입력
- 자사몰 일반상품, 벤더사 구입건, 비밀특가 상품은 제외
- `(부분취소)` 보조 행은 제외
- 0원 공구는 체크박스로 포함 가능

## 홈페이지로 배포하는 방법

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 안의 파일을 전부 저장소 첫 화면에 업로드합니다.
3. Streamlit Community Cloud에서 GitHub로 로그인합니다.
4. `Create app`을 누릅니다.
5. 저장소를 고르고 `Main file path`에 `app.py`를 입력합니다.
6. `Deploy`를 누릅니다.

배포가 끝나면 `https://원하는이름.streamlit.app` 형태의 홈페이지 주소가 생깁니다.

## 내 컴퓨터에서 먼저 확인하는 방법

Python이 설치되어 있다면 `run_app.bat`를 더블클릭합니다.
처음 실행할 때 필요한 패키지를 설치하므로 조금 걸릴 수 있습니다.

직접 명령어로 실행하려면:

```bash
pip install -r requirements.txt
streamlit run app.py
```
