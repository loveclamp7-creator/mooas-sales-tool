# 공동구매 매출 자동 매칭 v3

두 파일을 함께 업로드하면 최종 매출 기재용 엑셀을 만들어주는 Streamlit 앱입니다.

## 업로드 파일

1. 스룩 상품별 매출 파일
   - 상품코드
   - 상품명
   - 상품등록일
   - 최근주문일
   - 정상금액
2. 매출 기재용 파일
   - 년 / 월 / 진행일 / 밴더사 / 셀러 / 셀러 링크 / 팔로워 / 품목 / 판매금액 / 비고

## 처리 규칙

- 셀러명이 같고 품목명이 같거나 축약된 경우 판매금액에 정상금액 입력
- 같은 셀러·품목의 상품코드가 여러 개면 진행일과 상품등록일을 비교해 가장 가까운 항목 선택
- `탁상용 선풍기&핸디팬`처럼 여러 품목이 한 행에 있으면 관련 스룩 금액을 합산
- 셀러명이 `미르`와 `미르홈`처럼 비슷하지만 완전히 같지 않으면 한 행으로 합치지 않음
  - 매출 기재용 원본 행이 위
  - 스룩 후보 행이 바로 아래
- 스룩에는 있지만 기재용에는 없는 상품은 `스룩만 있음` 시트에 별도 정리
- 매출을 찾지 못한 기재용 행은 판매금액을 공란으로 유지

## 기존 GitHub 저장소에 적용

GitHub 저장소에서 `Add file → Upload files`를 누르고 아래 파일을 올립니다.

- `app.py`
- `matcher.py`
- `requirements.txt`
- `README.md`

같은 이름의 파일은 자동으로 교체됩니다. 기존 `core.py`, `vendor_mapping.csv`, `run_app.bat`는 남아 있어도 앱 실행에 영향을 주지 않습니다.
